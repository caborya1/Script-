⚙️ COMMON CUSTOMIZATIONS
───────────────────────────────────────────────────────────────
Want to rebirth at 5 million instead of 1 million?
  → Change: RebirthThreshold = 5000000

Want faster speed (3x instead of 2x)?
  → Change: SpeedMultiplier = 3

Don't want auto rebirth?
  → Change: AutoRebirth = false

🔧 HOW TO CUSTOMIZE
───────────────────────────────────────────────────────────────
Find this section in main.lua:

  AutoScript.Config = {
      AutoMoney = true,           ← ON/OFF
      AutoCollect = true,         ← ON/OFF
      AutoTrade = true,           ← ON/OFF
      AutoUpgrade = true,         ← ON/OFF
      AutoSpeed = true,           ← ON/OFF
      AutoRebirth = true,         ← ON/OFF
      RebirthThreshold = 1000000, ← Change amount
      SpeedMultiplier = 2,        ← Change speed
  }

Just edit true/false or change numbers!
